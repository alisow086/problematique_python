Exécutez Solution.py pour démarrer le codec.

Les mentions "À FAIRE" en commentaire indiquent les endroits où vous devez
insérer votre code.

La solution est divisée en 2 parties, le codage et le décodage. Ces deux
sections sont délimitées par le symbole # %% et peuvent être démarrées
séparément à l'aide de la commande "Run Cell" (ctrl+enter dans PyCharm
Professional et dans VS Code avec l'extension Python). Aucune donnée ne peut
passer directement du codage au décodage, i.e. sans passer par la variable
Data qui simule la couche physique.

Différences avec la version MATLAB :
  - Le tableau de cellules Data{N} devient un dictionnaire Data[N]. Les clés
    restent le nombre de bits, donc la numérotation à partir de 1 est
    conservée telle quelle.
  - Les fonctions retournent leurs sorties par un tuple au lieu de la liste
    [sortie1, sortie2] de MATLAB.
  - imread + im2double*255 devient np.asarray(Image.open(...), dtype=float).

Dépendances : numpy, pillow, matplotlib
  pip install numpy pillow matplotlib

Bonne programmation!
